# YoYoVideo v0.0.2

## 一键隐私模式

- 新增受保护媒体名单、4 位数字 PIN 和按星期设置的受限时段。首次使用需要自行设置并确认 PIN，没有默认 PIN。
- 设置后可一键开启；手动关闭以及修改保护名单、日程或 PIN 都需要验证。连续 5 次错误后冷却 30 秒，冷却状态跨重启保存。
- 手动开关持续到下一段合并后受限周期的开始。例如每天 09:00–18:00 受限，10:00 手动关闭会保持到次日 09:00，而不是在当天 18:00 被撤销。
- 进入受限时段时，已经加载、播放或暂停的受保护影片也会被隐藏、暂停并临时静音。多画面逐格处理，普通影片继续播放。
- 解除保护不会自动播放，也不会覆盖用户的音量/静音偏好。历史、最近打开、拖放、命令行、播放列表、自动连播、恢复和截图均执行准入检查。
- PIN 验证在后台执行；取消、失焦、重新开启保护或新周期会使过期的解锁结果失效。设置采用独立的原子配置文件，读取损坏配置时保持保护。

使用入口：**菜单 → 视图/设置 → 隐私设置…**。可通过当前媒体菜单或播放列表/历史条目旁的锁定图标标记媒体。快捷键可自行绑定，不占用现有默认按键。

## 界面和播放修正

- 普通 mpv 通知不再作为 `ignored mpv event` 警告出现在标题旁。
- 空态“打开文件”按钮改用中性半透明描边样式，保留 800×600 默认窗口。
- 视频宿主只附属于主窗口，避免隐藏的 PIN/设置窗口抢先成为视频父窗。
- 修正 macOS 视频宿主隐藏后脱离主窗口、坐标偏移和抢焦点的问题；重绘异步投递，避免播放线程与主线程互相等待。
- 切换到允许的新媒体时清除旧保护画面并解除旧暂停；停止、替换和重定向事件不再误触发自动连播。

## 保护边界与平台说明

- 这是当前应用进程内的访问/画面保护，不是无痕模式、文件加密或系统级防截图；不删除已有历史。文件移动或更换 URL 后可能需要重新标记。
- Windows 原生隐私场景、跨周期/重启、逐格隐藏及真实 OpenGL 合成门已在本机验证。macOS/Linux 的隐私窗口表面没有在本次本机验收中实测，不能把跨平台构建成功等同于全部原生隐私场景通过。
- macOS 使用 ad-hoc 签名，未做 Apple 公证；Windows 没有受信任的 Authenticode 证书，首次启动可能有系统提示。只从本项目发布页下载。
- Windows Setup、macOS 两种架构的应用包和 Linux AppImage 继续使用经过签名校验的稳定更新通道；Linux .deb 由包管理器/手动更新。Wayland 多画面仍不支持。

## One-click Privacy Mode

This release adds per-media protection, a user-chosen four-digit PIN, weekly restricted periods, and manual overrides that last until the next merged period starts. Turning protection on is immediate after setup; disabling it or changing protected items, schedules or the PIN requires verification.

Protected sessions are concealed, paused and temporarily muted even when they were already playing. Ordinary grid tiles continue. Unlocking never resumes playback automatically, and existing history and user audio preferences are preserved. Five failed PIN attempts impose a persisted 30-second cooldown. Cancelled or stale verification replies cannot unlock playback.

Routine mpv notifications no longer clutter the title, the empty-state opener uses a neutral translucent outline, and media replacement no longer inherits a privacy pause or treats a stopped file as automatic EOF navigation. macOS video hosts retain their parent relationship across hide/show, use proper AppKit coordinates, and request redraws asynchronously without stealing focus or blocking mpv.

Privacy controls are in-app, current-process protection—not encryption, incognito playback or OS-wide screenshot prevention. Windows native privacy and real OpenGL rendering were tested locally; macOS/Linux native privacy surfaces were not locally exercised. macOS remains ad-hoc signed without notarization; Windows has no trusted Authenticode certificate. The four signed stable updater channels are unchanged.
