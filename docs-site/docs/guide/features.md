# 功能一览

## 批量播放

把多个文件或整个文件夹拖进窗口即可进入批量模式。每个画面是一个独立的播放会话：

- 独立播放 / 暂停 / 停止
- 独立进度与音量
- 单格尺寸可以拖拽调整，松手后相邻格自动重排
- 关闭某一格不会影响其他格

命令行同样支持：

```powershell
yoyovideo-desktop.exe a.mp4 b.mkv c.mov
```

## 播放控制

| 能力 | 说明 |
| --- | --- |
| 进度跳转 | 输入时间精确跳转；时间轴支持鼠标拖拽与预览 |
| 章节 | 读取容器内章节，`Shift+←/→` 在章节与标记点之间跳转 |
| 标记点 | `Ctrl+M` 在当前时间打标记，之后可从时间轴直接跳过去 |
| A-B 循环 | `A` / `B` 设定两点，`Ctrl+A` 清除 |
| 倍速 | `[` / `]` 调整，`0` 复位 |
| 逐帧 | `,` / `.` 后退或前进一帧 |
| 截图 | `S` 保存当前画面 |

## 字幕与音轨

- 加载外部字幕文件，字幕随播放列表保留
- 字幕延迟、缩放、垂直位置可调
- 音频轨道切换，声道模式（立体声 / 单声道等）循环切换
- 字幕默认参数会随设置持久化

## 画面

- 缩放（`Z` / `X`）、旋转（`R`）、画面平移
- 常用视频滤镜预设
- 亮度、对比度、饱和度等画面参数调节

## 界面

- 自绘无边框窗口，标题栏与控制条可自动隐藏
- 播放列表与历史记录侧边栏
- 右键菜单与悬停子菜单
- 滚轮调节音量
- 中文字体优先的界面文案，可在设置中切换中英文
- 全部快捷键可在设置窗口中重新绑定

## 默认快捷键

这些是出厂绑定，可以在设置里改。

| 快捷键 | 动作 |
| --- | --- |
| `Space` | 播放 / 暂停 |
| `←` / `→` | 后退 / 前进 5 秒 |
| `↑` / `↓` | 音量增减 |
| `M` | 静音切换 |
| `[` / `]` / `0` | 减速 / 加速 / 复位倍速 |
| `A` / `B` / `Ctrl+A` | 设定 A 点 / 设定 B 点 / 清除循环 |
| `Ctrl+M` | 添加标记点 |
| `Shift+←` / `Shift+→` | 上一个 / 下一个章节或标记 |
| `J` | 打开跳转面板 |
| `P` | 打开操作面板 |
| `,` / `.` | 逐帧后退 / 前进 |
| `R` | 顺时针旋转 |
| `Z` / `X` | 缩小 / 放大 |
| `C` | 循环切换声道模式 |
| `F` | 全屏切换 |
| `S` | 截图 |
| `O` | 打开文件 |
| `U` | 打开网络地址 |

## 一键隐私模式（v0.0.2 起）

四位 PIN、逐条媒体保护、受限时段和持续到下一周期的手动开关。受保护的播放会话会暂停并隐藏，普通网格条目继续播放。见[使用说明](./privacy)。需要 v0.0.2 或更新版本。
